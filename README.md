# ระบบเบิกพัสดุ (Supply Withdraw)

> **มี 2 แบบให้เลือก**
> 1. **ระบบเบิกพัสดุ บน GitHub Pages / Cloudflare (ฟรี)** อยู่ในโฟลเดอร์ `docs/` เก็บข้อมูลใน Google Sheets ไม่ต้องมีเซิร์ฟเวอร์ ← ใช้งานอยู่
> 2. **แบบเซิร์ฟเวอร์ (Node.js)** อยู่ในโฟลเดอร์ `src/`, `public/` ระบบยืม-คืนอุปกรณ์ที่มีผู้ใช้/รหัสผ่านรายคน (แยกกัน รายละเอียดด้านล่าง)

## ระบบเบิกพัสดุ: เว็บ + Google Sheets

### ความสามารถ
- **เบิกพัสดุอย่างเดียว** (เวชภัณฑ์/วัสดุสิ้นเปลือง เบิกแล้วไม่ต้องคืน ไม่มีวันคืน) — ระบบยืม-คืนถูกตัดออกทั้งเว็บ ชีต และ PDF แล้ว
- กรอกแค่ **ชื่อ-นามสกุล** และ **แผนก** (เลือกจากรายการในชีต) แล้วเลือกพัสดุพร้อมจำนวน ได้หลายรายการในใบเบิกเดียว
- ส่งฟอร์มแล้ว **ตัดสต็อกใน Google Sheet ทันที** (เบิกของที่หมดได้ ยอดติดลบ) และบันทึก **วันเวลาที่เบิกถึงวินาที** (เช่น 24/10/2569 09:15:42)
- ระบบสร้าง **ใบเบิกเป็น PDF (A4)** อัตโนมัติ มีวันเวลาที่เบิก และช่องลงลายมือชื่อ **ผู้เบิก** และ **เจ้าหน้าที่พัสดุ ( เสาวลักษณ์ ถาน้อย )**
  (เปลี่ยนชื่อได้ที่ `STAFF_NAME` ใน `docs/config.js`) · เจ้าหน้าที่ออกเอกสารซ้ำได้จากหน้า "ประวัติเบิก"
- กดบันทึก/ดาวน์โหลด PDF แล้วมีหน้าต่างเล็กถาม **"ต้องการให้แนะนำวิธีการใช้งานหรือไม่?"**
  - **ใช่ แนะนำวิธี** → ป๊อปอัปภาพสาธิตวิธีบันทึกและพิมพ์ แยกแท็บ iPhone / Android / คอม (เลือกตามเครื่องให้) ปุ่มสุดท้าย **เข้าใจแล้ว บันทึกเลย** บันทึกไฟล์ให้ทันที
  - **ไม่ต้อง บันทึกเลย** → บันทึกไฟล์ทันที
  - บันทึกเสร็จแล้วขึ้นป๊อปอัป **"บันทึกไฟล์เรียบร้อย"** กลางจอ พร้อมชื่อไฟล์และบอกว่าไฟล์อยู่ที่ไหน (ปิดเองใน 6 วินาที)
  - iPhone: เปิดเมนูแชร์ (บันทึกไปยังไฟล์ / พิมพ์) · Chrome / Edge บนคอม: หน้าต่างบันทึกของระบบ · Android: ดาวน์โหลดลงโฟลเดอร์ ดาวน์โหลด
- **PDF ทุกไฟล์แบ่งหน้า A4 เอง**: ตารางยาวเกินหน้ามี**หัวตารางซ้ำทุกหน้า** (พร้อมหัวข้อ "(ต่อ)") ช่องลงชื่อไม่ถูกตัด ย้ายไปหน้าถัดไปทั้งบล็อก และมีเลขหน้า
- หน้าเจ้าหน้าที่เร็วขึ้นเมื่อมีข้อมูลมาก: ค้นหาด้วยดัชนี (ใบเบิก 3,000 ใบ: หน้าประวัติเบิก ~60 ms) แสดงประวัติทีละ 200 / 300 รายการพร้อมปุ่ม "แสดงเพิ่ม"
- หน้าเบิก: แสดง**ราคาต่อหน่วย**ของแต่ละรายการ ราคารวมของรายการที่เลือก และ**ราคารวมทั้งหมด** · กดยืนยันแล้วมี**ป๊อปอัปสรุป**รายการ จำนวน และยอดเงินก่อนบันทึกจริง
- ทุกการบันทึก (เบิก รับเข้า แก้พัสดุ เพิ่ม/ลบรายการ ลบใบเบิก สร้าง PDF รีเฟรช) มี**ป๊อปอัปกลางจอ** "กำลังดำเนินการ" → "สำเร็จ" (หรือแจ้งข้อผิดพลาด)
- เจ้าหน้าที่รีเฟรชหน้า: แสดงข้อมูลล่าสุดของแท็บนั้นทันที แล้วดึงข้อมูลใหม่จาก Google Sheets ตามมา · เชื่อมต่อ Apps Script ล่วงหน้าระหว่างโหลดหน้า
- **ของหมด / เหลือ 0 ต้องติดต่อก่อนเบิก**: แถบแจ้งในหน้าเบิกพัสดุและหน้าพัสดุคงเหลือ พร้อมปุ่ม **โทร 081-734-5983** (กดโทรได้ทันที) และ **สอบถามทาง LINE** (เปิด LINE ทันที)
  · กด "+ เลือก" ที่ของที่หมด มีป๊อปอัปให้ติดต่อก่อน (กด "สอบถามแล้ว เลือกเบิก" จึงเลือกได้) · ป๊อปอัปยืนยันการเบิกเตือนซ้ำถ้ามีรายการที่ของไม่พอ
  · เปลี่ยนเบอร์/ลิงก์ได้ที่ `CONTACT_PHONE` / `CONTACT_LINE` ใน `docs/config.js`
- หน้า **วิธีใช้งาน**: ภาพหน้าจอจริงทีละขั้น (กรอบสีส้ม = ปุ่มที่ต้องกด) · ทางลัด 4 หัวข้อ · วิธีบันทึก/พิมพ์ PDF เป็นภาพแยก iPhone / Android / คอม · คำถามที่พบบ่อย
- หน้าเลือกพัสดุ: ค้นหาแบบไม่สนช่องว่าง (เช่น `airway100`), ดูเฉพาะที่มีของ / ที่เลือกไว้, กระโดดตามตัวอักษร A–Z / ก–ฮ
- หน้า **พัสดุคงเหลือ** แสดงยอดล่าสุดจากชีต อัปเดตเองทุก 45 วินาที
- **เมนูเจ้าหน้าที่**: หน้าแรก · เบิกพัสดุ · พัสดุคงเหลือ · ภาพรวม · **ประวัติ** (แท็บ ใบเบิก / ความเคลื่อนไหวสต็อก) ·
  **รายงาน** (แท็บ รายงาน: สรุปรายปี · สรุปการเบิก · พัสดุคงเหลือ · มูลค่ารับเข้า–จ่ายออก · ส่งออก CSV / แท็บ **งบประมาณแผนก**) · **บริษัท** · **ตั้งค่า** (แท็บ รายการตัวเลือก / Google Sheet)
  — เปลี่ยนเมนูไม่ต้องรอโหลดข้อมูลใหม่ (ดึงใหม่เมื่อข้อมูลเก่ากว่า 30 วินาที) · Apps Script อ่านข้อมูลได้พร้อมกันหลายเครื่องโดยไม่ต้องรอคิว
- **โหมดเจ้าหน้าที่พัสดุ (PIN)** — ปุ่ม **เจ้าหน้าที่พัสดุ** มุมขวาบน ใส่รหัสด้วย**แป้นตัวเลขแบบหน้าจอล็อก iPhone** (จุด 4 จุด ปุ่มวงกลม ใส่ครบแล้วตรวจเอง ผิด = จุดสั่น)
  จำนวนหลักตั้งที่ `PIN_LENGTH` ใน `docs/config.js` (ต้องตรงกับ `ADMIN_PIN` ใน Apps Script)
  - **Live board** (หน้าภาพรวม → ทางลัด Live board หรือ `#/board`): จอทีวีในห้องพัสดุ พื้นมืด ตัวใหญ่ นาฬิกา ยอดวันนี้ ใบเบิกล่าสุด
    ใกล้หมดสต็อก ใกล้หมดอายุ และแผนกที่เบิกวันนี้ · ดึงข้อมูลใหม่ทุก 60 วินาที · ใบเบิกใหม่เรืองแสงพร้อมป้าย "ใหม่" และเสียงเตือน (กด "เปิดเสียง")
    · ปุ่มเต็มจอ · หน้าจอไม่ดับเอง (เบราว์เซอร์ที่รองรับ) — เข้าระบบเจ้าหน้าที่ในเครื่องที่ต่อทีวีแล้วเปิดหน้านี้ค้างไว้
  - **มูลค่าพัสดุในคลังตอนนี้** (การ์ดบนหน้า ภาพรวม, พัสดุคงเหลือ และ Live board): ผลรวม คงเหลือ × ราคาต่อหน่วย ทุกรายการ
    อัปเดตทันทีหลังเบิก/รับเข้า/ดึงข้อมูลใหม่ · บอกจำนวนรายการ/ชิ้น หมวดที่มูลค่าสูงสุด 3 อันดับ และเตือนรายการที่มีของแต่ยังไม่ใส่ราคา
  - **สรุปรายปี — รายงานบัญชีวัสดุประจำปี (PDF แนวนอน)** ที่หน้า **รายงาน** → ขอรายงาน: แบบฟอร์มเดียวกับรายงานบัญชีวัสดุ
    (ชื่อหน่วยงาน · **รหัสหน่วยเบิกจ่าย กรอกเอง** · ประเภทวัสดุ · ตาราง ยอดยกมา / รับ / จ่าย / ยอดคงเหลือ แต่ละช่องมี จำนวน ราคาต่อหน่วย ราคารวม · ยอดรวมสุทธิ)
    เลือก **ปีงบประมาณ** (1 ต.ค.–30 ก.ย.) หรือ **ปีปฏิทิน** · กรอกชื่อ **ประธานกรรมการ** และ **กรรมการ 6 คน** พร้อม dropdown ตำแหน่ง
    (พยาบาลวิชาชีพชำนาญการ / ชำนาญการพิเศษ / ปฏิบัติการ / พิมพ์เอง) — เครื่องจำค่าที่กรอกไว้ใช้ปีถัดไป · มีป๊อปอัปสรุปให้ยืนยันก่อนสร้าง
    · ใช้ฟอนต์ **TH Sarabun PSK** (เฉพาะรายงานนี้) ความกว้างคอลัมน์ตามแบบฟอร์ม ตัวเลขยาวย่อเฉพาะช่องนั้นให้พอดี
    · หัวตารางและช่องลงนามกรรมการ 7 ท่านขึ้นทุกหน้า · รับ = คงเหลือ + จ่าย − ยกมา (ตามสูตรในแบบฟอร์ม) มูลค่าใช้ราคาต่อหน่วยปัจจุบัน
  - **งบประมาณแผนก** (เมนู รายงาน → แท็บ งบประมาณแผนก, `#/budget`): ตั้งงบให้แต่ละแผนกต่อ**ปีงบประมาณ** (1 ต.ค. – 30 ก.ย.)
    ทุกใบเบิกตัดจากงบของแผนกนั้นอัตโนมัติ (มูลค่าตามราคา ณ วันที่เบิก · แก้/ลบใบเบิกแล้วงบคำนวณใหม่)
    · การ์ดแต่ละแผนก: งบ ตัดไป คงเหลือ % (ใช้เกิน 80% สีส้ม เกินงบสีแดง) · **ประวัติการตัดงบทุกรอบ**: ใบเบิกไหน ตัดจากงบแผนกไหน เท่าไร
    แยกตามหมวดหมู่พัสดุ และงบคงเหลือหลังใบนั้น · เพิ่ม/ลดงบกลางปีได้ (มีหมายเหตุ) · ส่งออก CSV · หน้าใบเบิกบอกงบคงเหลือหลังใบนั้น
    · เก็บในแท็บ **งบประมาณแผนก** ในชีต (1 แถว = ตั้ง/เพิ่ม/ลดงบ 1 ครั้ง)
  - **บริษัทผู้จำหน่าย** (เมนู **บริษัท** ด้านบน, `#/suppliers`): ผู้ติดต่อ เบอร์โทร (แตะเพื่อโทร) อีเมล หมายเหตุ
    จำนวนครั้งที่ส่งของ ยอดซื้อรายปี/รวม พัสดุที่ส่งพร้อมราคาล่าสุด และประวัติแยกตามใบส่งของ · แก้ชื่อบริษัทแล้วประวัติรับเข้าเดิมเปลี่ยนตาม
  - **กระดิ่งแจ้งเตือน** (มุมขวาบน เฉพาะเจ้าหน้าที่): ตัวเลขบอกจำนวนเรื่องที่ต้องดู (สีแดง = มีของหมดอายุภายใน 30 วัน / หมดอายุแล้ว)
    - **ใกล้หมดอายุ**: ล็อตที่จะหมดอายุภายใน `EXPIRY_ALERT_MONTHS` เดือน (ตั้งต้น 8 เดือน ใน `docs/config.js`) และล็อตที่หมดอายุแล้ว
      ใช้วันหมดอายุที่กรอกตอนรับเข้า · จำนวนคงเหลือของแต่ละล็อตประมาณแบบเข้าก่อนออกก่อน (ล็อตเก่าที่ใช้หมดแล้วไม่เตือน)
    - **ใกล้หมดสต็อก**: พัสดุที่คงเหลือถึงจุดสั่งซื้อขั้นต่ำแล้ว · แตะรายการเพื่อเปิดรายละเอียด/รับเข้า
  - **ประวัติเบิก**: เลือกช่วงเวลา **ทุกเดือน / วันนี้ / เลือกเดือน** (บอกจำนวนใบแต่ละเดือน) ค้นหา ส่งออก CSV
    และ**ลบใบเบิก**ที่บันทึกผิดได้ (มีป๊อปอัปยืนยันก่อนลบ เลือกได้ว่าจะคืนจำนวนพัสดุเข้าสต็อกหรือไม่ · ลบแล้วขึ้นป๊อปอัป "ลบใบเบิกเรียบร้อย" กลางจอ · เลขที่ของใบที่ลบจะไม่ถูกใช้ซ้ำ)
  - **หน่วยนับ** และ **สถานที่เก็บ** เป็น dropdown (ตั้งต้น: ชิ้น กล่อง ขวด ม้วน โหล) เพิ่มใหม่ได้จากเมนู "+ เพิ่ม…ใหม่" ในฟอร์ม หน้าตั้งค่า หรือพิมพ์ในแท็บ **หน่วยนับ** / **สถานที่เก็บ** ในชีต
  - **ราคาต่อหน่วย (บาท)** ใส่ได้ในฟอร์มพัสดุ (ต่อ 1 หน่วยนับที่เลือก) · ใบเบิกเก็บราคา ณ วันที่เบิก (ราคาเปลี่ยนภายหลัง ใบเดิมไม่เปลี่ยน ·
    ใบที่เบิกก่อนใส่ราคาใช้ราคาปัจจุบัน) · ใบเบิก PDF มีราคา/หน่วย จำนวนเงิน และ**รวมเป็นเงิน** พร้อมตัวอักษร (เช่น สองพันห้าร้อยเอ็ดบาทถ้วน)
  - **รับเข้าสต็อก** และ **เพิ่มพัสดุใหม่**: เลือก **บริษัท/ผู้จำหน่าย** จากรายการ (เพิ่มบริษัทใหม่ได้ทันทีจากเมนู "+ เพิ่มบริษัทใหม่…" บันทึกลงแท็บ **บริษัท** ในชีต)
    **วันหมดอายุ** เลือกจากปฏิทินเท่านั้น (พิมพ์เองไม่ได้) และ **เลขใบส่งของ** — แสดงในประวัติสต็อกและส่งออก CSV ได้
  - **แก้ไขใบเบิก** (ประวัติเบิก → เปิดใบเบิก → แก้ไขใบเบิก): เพิ่ม/ลดจำนวน เพิ่มพัสดุ (ค้นหาแล้วกด Enter) ลบรายการ แก้ชื่อ แผนก หมายเหตุ
    สต็อกปรับตามทันที (เพิ่ม = ตัดสต็อกเพิ่ม, ลด/ลบ = คืนเข้าสต็อก บันทึกในประวัติสต็อก) แล้วได้ **PDF ฉบับแก้ไข** (มุมขวาบนเขียน "ฉบับแก้ไข" พร้อมวันเวลา) เลขที่เดิม
  - **แก้ยอดคงเหลือได้อิสระ**: ปุ่ม **แก้ยอดคงเหลือ** (หน้าพัสดุคงเหลือ) พิมพ์ยอดใหม่หลายรายการในตารางเดียว (ค้นหา/กรองหมวดหมู่/สถานที่เก็บ, Enter ไปแถวถัดไป)
    · ช่อง **จำนวนคงเหลือ** ในฟอร์มแก้ไขพัสดุ · ปุ่ม **แก้ยอด / ตรวจนับ** · ใส่ยอดติดลบได้ และตัดชำรุดเกินยอดในระบบได้ — ทุกการแก้บันทึกในประวัติสต็อกว่า "ปรับปรุงยอด"
  - **เพิ่มพัสดุใหม่: ระบบตั้งรหัสให้เอง** ต่อจากรหัสล่าสุด (เช่น NSO-301 → NSO-302) เจ้าหน้าที่ไม่ต้องกรอก
  - **สรุปรายเดือน (PDF)**, ตรวจนับ, ตัดชำรุด, แก้พัสดุ, จัดการแผนก/หมวดหมู่/บริษัท (หน้า ตั้งค่า), ภาพรวม และประวัติสต็อก

  - **สรุปมูลค่ารับเข้า–จ่ายออก (PDF / CSV)** ที่หน้า ภาพรวม หรือ พัสดุคงเหลือ: เลือก **รายเดือน / รายปี** และ **รับเข้า / จ่ายออก / ทั้งสองอย่าง**
    มียอดรวม สรุปรายเดือน (รายปี) สรุปตามรายการพัสดุ และรายการรับเข้าทั้งหมด (บริษัท เลขใบส่งของ) · รับเข้าใส่**ราคาต่อหน่วยของล็อต**ได้ (ไม่ใส่ = ราคาปัจจุบัน)
    · ยอดยกมาตอนตั้งระบบ/ใส่ไฟล์สต็อกใหม่ไม่นับเป็นรับเข้า
  - **รายงานพัสดุคงเหลือ (PDF / CSV)** ที่หน้า พัสดุคงเหลือ หรือ ภาพรวม: เลือก **รายเดือน / รายปี** — ยอด**จ่ายออก** (จำนวน มูลค่า แยกรายการ)

  - **สรุปรายงาน (PDF)** ที่หน้า ภาพรวม หรือ ประวัติเบิก: เลือก **รายเดือน / รายปี** และ **ทุกแผนก / เฉพาะแผนก**
    มียอดรวม **มูลค่ารวม (บาท)**, พัสดุที่ถูกเบิกพร้อมราคา/หน่วยและมูลค่า, สรุปรายเดือน (รายปี), สรุปตามแผนก (ทุกแผนก), รายการใบเบิกทั้งหมดพร้อมมูลค่าแต่ละใบ
    และช่องลงชื่อ **ผู้จัดทำรายงาน ( เสาวลักษณ์ ถาน้อย )** (ชื่อจาก `STAFF_NAME`) / หัวหน้างานพัสดุ

### ขั้นที่ 2: เชื่อม Google Sheets เพื่อให้ทุกเครื่องใช้ข้อมูลพัสดุ/สต็อกชุดเดียวกัน (ประมาณ 10 นาที)

**Google Sheet มาจากไหน?** สร้างใหม่เองด้วยบัญชี Google (Gmail หรือบัญชี Google Workspace ของโรงพยาบาล) ไม่ต้องมีชีตเดิม
ชีตเปล่า 1 ไฟล์พอ ระบบจะสร้างแท็บและใส่ข้อมูลพัสดุ/แผนกให้เองในข้อ 6
ชีตเป็นของบัญชีที่สร้าง และเว็บจะบันทึกข้อมูลในนามบัญชีนั้น จึงแนะนำให้ใช้บัญชีกลางของงานพัสดุแทนบัญชีส่วนตัว
และไม่ต้องแชร์ชีตให้ผู้ใช้คนอื่น ทุกคนใช้งานผ่านเว็บได้เลย

ทำบนคอมพิวเตอร์ (หน้า Apps Script ใช้บนมือถือไม่สะดวก)
1. เข้าสู่ระบบบัญชี Google แล้วเปิด https://sheets.new (หรือ Google Drive → ใหม่ → Google ชีต) แล้วตั้งชื่อ เช่น "ระบบเบิกพัสดุ"
2. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. เปิดไฟล์ [`docs/apps-script/AllInOne.gs`](docs/apps-script/AllInOne.gs) บน GitHub แล้วกดปุ่ม **Raw** (หน้าข้อความล้วน)
   กด **Ctrl+A** แล้ว **Ctrl+C** เพื่อคัดลอกทั้งไฟล์ (ไฟล์นี้รวม Code + Core + SeedData ไว้แล้ว)
   > อย่าคัดลอกจากหน้า Pull Request / "Files changed" เพราะจะมีเครื่องหมาย `+` ติดมาทุกบรรทัด
4. กลับมาที่ Apps Script ให้เหลือไฟล์ `Code.gs` ไฟล์เดียว (ถ้าเคยสร้าง `Core` / `SeedData` ไว้ ให้ลบทิ้ง)
   ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้ววาง (Ctrl+V) จากนั้นแก้บรรทัด `var ADMIN_PIN = '1234';` เป็น PIN ของคุณเอง
5. กด **บันทึก** (รูปแผ่นดิสก์ หรือ Ctrl+S) ต้องบันทึกผ่านโดยไม่มีแถบสีแดง
   > ถ้าขึ้น *"พยายามใช้ setup แล้ว แต่บันทึกไม่ได้"* แปลว่าโค้ดที่วางไม่ครบหรือมีอักขระเกินมา
   > ให้ลบเนื้อหาใน `Code.gs` ทั้งหมดแล้วคัดลอกจากหน้า Raw ใหม่อีกครั้ง
6. เลือกฟังก์ชัน **`setup`** ในแถบด้านบน แล้วกด **เรียกใช้ (Run)**
   ครั้งแรก Google จะขอสิทธิ์ ให้กด ตรวจสอบสิทธิ์ → เลือกบัญชี → ขั้นสูง (Advanced) → ไปที่โปรเจกต์ (ไม่ปลอดภัย) → อนุญาต (Allow)
   จากนั้นในชีตจะมีแท็บ อุปกรณ์ (= รายการพัสดุ) / ประวัติการเบิก (= ใบเบิกทุกใบ) / หน่วยงาน (= แผนก) ฯลฯ พร้อมข้อมูลจาก SeedData
   > รัน `setup` ซ้ำได้จนกว่าจะเริ่มมีการเบิกจริง (จะเขียนทับรายการพัสดุ แผนก และประวัติสต็อกด้วยข้อมูลใน SeedData)
   > หลังเริ่มใช้งานแล้ว ระบบจะไม่ยอมเขียนทับ เพื่อป้องกันข้อมูลหาย
7. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)** → ไอคอนเฟือง เลือก **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
   - กด Deploy แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
8. กลับมาที่ GitHub เปิดไฟล์ [`docs/config.js`](docs/config.js) กดรูปดินสอ (Edit) แล้ววาง URL ลงใน `API_URL: '...'`
   และแก้ `HOSPITAL_NAME` เป็นชื่อหน่วยงานของคุณ (แสดงบนหัวกระดาษ PDF) และ `STAFF_NAME` ชื่อเจ้าหน้าที่พัสดุ (ใต้ช่องลงชื่อในใบเบิก)

### ใช้งานบนมือถือและ iPad
- เปิดลิงก์เว็บใน Safari (iPhone/iPad) หรือ Chrome (Android) หน้าจอปรับตามขนาดเครื่องอัตโนมัติ ทั้งแนวตั้งและแนวนอน
- **เพิ่มเป็นไอคอนบนหน้าจอโฮม** ให้เปิดเต็มจอเหมือนแอป
  - iPhone / iPad: Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
  - Android: Chrome → เมนู ⋮ → **เพิ่มลงในหน้าจอหลัก** (หรือ ติดตั้งแอป)
- **บันทึกใบเบิก (PDF)** บน iPhone / iPad: แตะ "บันทึก PDF" แล้วเลือก **บันทึกไปยังไฟล์** (เก็บในแอปไฟล์) หรือ **พิมพ์** / AirDrop
  บน Android ไฟล์จะอยู่ในโฟลเดอร์ดาวน์โหลด
- รองรับ iOS / iPadOS 15.4 ขึ้นไป และ Android ที่ใช้ Chrome รุ่นปัจจุบัน

### ใส่สต็อกชุดใหม่ทั้งหมดจากไฟล์ (แทนที่ของเดิม)
รายการพัสดุและยอดคงเหลือใน `docs/seed-data.js` ตอนนี้เป็นไปตาม**ไฟล์ Stock วันที่ 21 ตุลาคม 2569** (301 รายการ รหัส NSO-001 ถึง NSO-301 เรียงตามไฟล์)
ใน Apps Script (วาง `AllInOne.gs` ล่าสุดแล้ว) เลือกฟังก์ชัน **`loadNewStock`** แล้วกด **เรียกใช้** 1 ครั้ง
ระบบจะลบรายการพัสดุเดิม ใบเบิก และประวัติสต็อกทั้งหมด แล้วใส่รายการและยอดตามไฟล์ (บันทึกเป็นรับเข้า "ยอดยกมาเริ่มต้น")
รายชื่อแผนกอยู่ครบ · ย้อนกลับได้ที่ Google Sheet → ไฟล์ → ประวัติเวอร์ชัน

### วิธีใช้งาน (ป๊อปอัปสอนใช้งาน)
หน้า **วิธีใช้งาน** (`#/help`, เมนูด้านบนของผู้ใช้ทั่วไป) มีขั้นตอนการเบิกพร้อมภาพ การเบิกหลายรายการในใบเดียว
และวิธีบันทึก/พิมพ์ใบเบิกแบบละเอียดแยก iPhone / Android / คอมพิวเตอร์ (เลือกแท็บตามเครื่องให้อัตโนมัติ)
หน้านี้มีปุ่มลูกศรสีฟ้าลอยด้านล่างจอ **เลื่อนลงอ่านต่อ** (แตะเพื่อเลื่อนลง เลื่อนแล้วย่อเหลือลูกศร ถึงท้ายหน้าแล้วหายไป)
หน้าแรกและหน้าเบิกมีแถบแจ้งเตือนสีส้ม "โปรดอ่านวิธีใช้งานก่อนเบิกพัสดุ" ลิงก์ไปหน้านี้ และหน้าบันทึกสำเร็จมีลิงก์ไปหัวข้อบันทึก/พิมพ์
ทุกครั้งที่เปิดเว็บจะมีป๊อปอัปสอนใช้งาน 8 หน้า พร้อมภาพประกอบ (`docs/tour/`) ปิดได้ทันทีที่ปุ่ม **✕ ปิด** มุมขวาบน หรือ ข้าม
เปิดดูอีกครั้งได้ที่ปุ่ม **?** มุมขวาบน · ถ้าหน้าเว็บเปลี่ยน ถ่ายภาพประกอบใหม่แล้วแทนไฟล์ใน `docs/tour/`
ป๊อปอัปนี้สั่นเบา ๆ เตือน (Android สั่น 2 จังหวะสั้น · iPhone iOS 18 ขึ้นไปสั่นสั้น ๆ 1 ครั้ง) — เบราว์เซอร์ทุกตัวไม่ยอมให้เว็บสั่นก่อนผู้ใช้แตะจอ
จึงสั่นตอนแตะครั้งแรกในป๊อปอัป (แตะปุ่มปิดจะไม่สั่น) ถ้าผู้ใช้แตะหน้าเว็บมาก่อนแล้วจะสั่นทันทีที่ป๊อปอัปเด้ง

### ภาพสาธิตวิธีบันทึกใบเบิก
หลังกด **ยืนยันการเบิก** มีเสียงเตือนสั้น ๆ (Android สั่นด้วย) และในหน้าเบิกสำเร็จมีแถบสีแดง **"สำคัญ! อย่าลืมบันทึกใบเบิก — ดูวิธี ›"**
กดปุ่ม **บันทึก PDF / ดาวน์โหลด PDF** แล้วจะถามก่อนว่า **"ต้องการให้แนะนำวิธีการใช้งานหรือไม่?"** (ดูหัวข้อความสามารถด้านบน)
ป๊อปอัปภาพสาธิต (หัวสีแดง กระดิ่งสั่น) มี 3 แท็บ: **iPhone** (6 ขั้น: บันทึกไปยังไฟล์ + พิมพ์), **Android** (5 ขั้น: ดาวน์โหลด + พิมพ์), **คอม** (5 ขั้น: หน้าต่างบันทึก + Ctrl+P)
เปิดได้จากหน้าวิธีใช้งาน (หัวข้อบันทึกและพิมพ์) และหน้า PDF ในป๊อปอัปสอนใช้งานด้วย · ภาพเป็นภาพจำลองหน้าจอ อยู่ใน `docs/tour/save/`
(เสียงจะไม่ดังถ้า iPhone เปิดโหมดเงียบ · ผู้ที่ตั้งค่า "ลดการเคลื่อนไหว" จะไม่มีภาพเคลื่อนไหวและไม่สั่น)

### เริ่มใช้งานจริง: ล้างข้อมูลทดลอง
ใน Apps Script เลือกฟังก์ชัน **`resetForLaunch`** ที่แถบด้านบน แล้วกด **เรียกใช้** 1 ครั้ง
ระบบจะลบใบเบิก รายการในคำขอ และประวัติสต็อกทั้งหมด แล้วตั้งยอดคงเหลือทุกรายการเป็น 0
(รายชื่อพัสดุ รายชื่อแผนก และหมวดหมู่อยู่ครบ · เลขที่เอกสารเริ่มใหม่ที่ WD..-001)
จากนั้นใส่ยอดจริงในคอลัมน์ `available_qty` ของแท็บอุปกรณ์ หรือใช้ปุ่ม รับเข้า / ตรวจนับ บนเว็บ
ถ้ารันผิด ย้อนกลับได้ที่ Google Sheet → **ไฟล์ → ประวัติเวอร์ชัน**

### จัดการรายชื่อพัสดุใน Google Sheet
เจ้าหน้าที่เปิดชีตได้จากเว็บ: กดปุ่ม **เจ้าหน้าที่พัสดุ** ใส่ PIN แล้วไปที่เมนู **Google Sheet** (ลิงก์ส่งมาจาก Apps Script เฉพาะคนที่ใส่ PIN ถูก
ต้องวาง `AllInOne.gs` เวอร์ชันล่าสุดและ Deploy → New version ก่อน หรือใส่ `SHEET_URL` ใน `config.js` เอง) ชีตยังเปิดได้เฉพาะบัญชี Google ที่ได้รับสิทธิ์ตามปุ่มแชร์ของชีต

| แท็บ | ใช้ทำอะไร |
|---|---|
| **อุปกรณ์** | รายการพัสดุ: `code` รหัส, `name` ชื่อ, `category` หมวดหมู่, `unit` หน่วยนับ, `available_qty` คงเหลือ, `min_qty` จุดเตือนใกล้หมด, `location` ที่เก็บ, `active` (1 = เปิด, 0 = ปิด), `price` ราคาต่อหน่วย (บาท) |
| **หน่วยนับ** / **สถานที่เก็บ** | ตัวเลือกใน dropdown ของฟอร์มพัสดุ (`name`) เพิ่ม/ลบในชีต หน้าตั้งค่า หรือจากฟอร์มได้ |
| **บริษัท** | รายชื่อ **บริษัท/ผู้จำหน่าย** (`name` ชื่อ, `contact` ผู้ติดต่อ, `phone` เบอร์โทร, `email` อีเมล/LINE, `note` หมายเหตุ) เพิ่ม/แก้ในชีต หน้าบริษัทผู้จำหน่าย หน้าตั้งค่า หรือจากฟอร์มรับเข้าได้ |
| **งบประมาณแผนก** | งบประมาณแต่ละแผนกต่อปีงบประมาณ (`department` แผนก, `fiscal_year` ปีงบ พ.ศ. เช่น 2570, `amount` จำนวนเงิน ติดลบ = ลดงบ, `note`, `created_at`) งบของแผนก = ผลรวมทุกแถวของปีนั้น · ตั้ง/ปรับในหน้า งบประมาณแผนก ของเว็บ |
| **หน่วยงาน** | รายชื่อ **แผนก** ที่แสดงให้เลือกในฟอร์ม: `name` ชื่อย่อ (เช่น ICU), `full_name` ชื่อเต็ม (แสดงในใบเบิก) |
| **ประวัติการเบิก** (เดิมชื่อ คำขอยืม เปลี่ยนชื่อให้อัตโนมัติ) | 1 แถวต่อใบเบิก ล่าสุดอยู่บน: เลขที่ **วันที่เวลาที่เบิก (ถึงวินาที)** ผู้เบิก แผนก **รายการพัสดุ** จำนวนรวม หมายเหตุ · คอลัมน์หัว**สีเทา**ท้ายตารางเป็นข้อมูลระบบ (ห้ามแก้) |
| **รายการในคำขอ** | ข้อมูลระบบ: พัสดุแต่ละชิ้นในใบเบิก |
| **ประวัติสต็อก** | ทุกการเคลื่อนไหวของสต็อก ตรวจสอบย้อนหลังได้ · การรับเข้ามี `supplier` บริษัท, `expiry_date` วันหมดอายุ (ปี ค.ศ. YYYY-MM-DD), `delivery_no` เลขใบส่งของ |
| **รายการเบิก** (แท็บแรก) | 1 แถวต่อพัสดุ 1 รายการ: วันที่เวลาที่เบิก, เลขที่, ผู้เบิก, แผนก, **ชื่อพัสดุ, จำนวน, หน่วย, ราคาต่อหน่วย, รวมเงิน** (ล่าสุดอยู่บน ใช้ตัวกรอง/Pivot ได้) — ระบบเขียนให้ ไว้ดูอย่างเดียว |

คอลัมน์ที่หัวเป็น**สีฟ้าอ่อน** (เช่น รายการพัสดุ, ชื่อพัสดุ, เบิกไปแล้วรวม) ระบบเขียนให้อัตโนมัติเพื่อให้อ่านง่าย
แก้ในคอลัมน์เหล่านี้ไม่มีผล (จะถูกเขียนทับครั้งถัดไป)

ข้อมูลตั้งต้นใน `docs/seed-data.js`
- **คงเหลือ** = คอลัมน์ "คงเหลือ" ของ stock NSO ณ วันที่ 8 เมษายน 2569 (ช่องว่าง = 0)
- **จุดเตือนใกล้หมด** (`min_qty`) = ปริมาณจ่าย 6 เดือน ÷ 6 คือเตือนเมื่อเหลือไม่พอใช้ประมาณ 1 เดือน
- **หน่วยนับ** เดาจากชื่อพัสดุ (กล่อง/โหล/ม้วน/ฯลฯ ไม่พบ = ชิ้น) ตรวจและแก้ในแท็บอุปกรณ์ได้

**แก้ยอดคงเหลือในชีตโดยตรงได้** — แก้คอลัมน์ `available_qty` (คงเหลือ)
เว็บจะเห็นยอดใหม่ภายในประมาณ 20 วินาที (ยอดสต็อกสำหรับผู้ใช้ทั่วไปเก็บในแคชของ Apps Script 20 วินาที) เมื่อเปลี่ยนหน้า กดรีเฟรช หรือสลับกลับมาที่แท็บ/แอป
- การแก้ในชีตโดยตรง **ไม่ถูกบันทึกในประวัติสต็อก** ถ้าต้องการประวัติครบ ให้ใช้ปุ่ม รับเข้า / ตรวจนับ ในโหมดเจ้าหน้าที่บนเว็บ
- แก้ชื่อ หน่วย ที่เก็บ และรายชื่อแผนกในชีตได้เลย
- **เพิ่มพัสดุใหม่ในชีตได้**: พิมพ์แถวใหม่ท้ายแท็บอุปกรณ์ ใส่ `code` (ไม่ซ้ำ), `name`, `unit`, `available_qty` (และ `category`, `min_qty`, `location` ถ้ามี)
  เว้น `id` และ `active` ว่างไว้ได้ ระบบตั้ง `id` ถัดไปให้และถือว่าเปิดใช้งาน (`unit` ว่าง = ชิ้น) · หรือเพิ่มผ่านเว็บ: เจ้าหน้าที่ → พัสดุคงเหลือ → + เพิ่มพัสดุ
- ถ้าแก้ในชีตตรงจังหวะที่มีคนกดบันทึกบนเว็บพอดี ค่าที่แก้อาจถูกเขียนทับ ให้ตรวจยอดอีกครั้งหลังแก้

### สต็อกเปลี่ยนอย่างไร

| การทำรายการ | คงเหลือ (`available_qty`) |
|---|---|
| เบิก | ลดลงทันที |
| รับเข้า (เจ้าหน้าที่) | เพิ่มขึ้น |
| ตรวจนับ (เจ้าหน้าที่) | ตั้งเป็นยอดที่นับได้จริง |
| ตัดชำรุด/สูญหาย (เจ้าหน้าที่) | ลดลง |
| ลบใบเบิก แบบคืนสต็อก (เจ้าหน้าที่) | เพิ่มกลับเท่าจำนวนในใบ (บันทึกว่า "คืนจากใบเบิกที่ลบ") |

**เบิกของที่หมดได้** — ยอดคงเหลือจะ**ติดลบ** (เช่น -5 = ค้างจ่าย 5) เมื่อ **รับเข้า** ครั้งถัดไป ยอดที่รับเข้าจะหักล้างยอดติดลบก่อนโดยอัตโนมัติ (เช่น -5 รับเข้า 20 → เหลือ 15)

เลขที่เอกสาร: `WD69-001` = ปี พ.ศ. 2 หลัก + ลำดับในปีนั้น (เริ่ม 001 ใหม่ทุกปี เกิน 999 เป็น 4 หลัก)
วันเวลาทุกรายการบันทึกถึงวินาที ต้องตั้งเขตเวลาเป็นไทย: Apps Script → **การตั้งค่าโปรเจกต์ (รูปเฟือง) → เขตเวลา = (GMT+07:00) Bangkok**
และใน Google Sheet → **ไฟล์ → การตั้งค่า → เขตเวลา = (GMT+07:00) Bangkok**

## แบบเซิร์ฟเวอร์ (Node.js)

เว็บแอปสำหรับให้หน่วยงานภายในโรงพยาบาลยืม-คืนครุภัณฑ์/อุปกรณ์การแพทย์จากคลังกลาง
โดย **ยอดสต็อกคงเหลือเชื่อมกับการยืม-คืนแบบอัตโนมัติ** และบันทึกประวัติการเคลื่อนไหวทุกครั้ง

## ความสามารถหลัก

| เมนู | รายละเอียด |
|---|---|
| **ภาพรวม** | จำนวนอุปกรณ์ทั้งหมด / คงเหลือพร้อมให้ยืม / กำลังถูกยืม / รออนุมัติ / เกินกำหนดคืน, รายการสต็อกต่ำกว่าจุดขั้นต่ำ, ความเคลื่อนไหวล่าสุด |
| **คลังอุปกรณ์** | ค้นหา กรองตามหมวด ดูยอด *คงเหลือ / ทั้งหมด / ถูกยืม* แบบเรียลไทม์, ดูว่าใครยืมอยู่, ประวัติสต็อกรายชิ้น, รับเข้า, ตรวจนับปรับยอด, ตัดชำรุด/สูญหาย, นำเข้า/ส่งออก CSV |
| **ยืมอุปกรณ์** | เลือกหลายรายการในคำขอเดียว ระบบตรวจว่าไม่เกินยอดคงเหลือ, เจ้าหน้าที่คลังเลือก "จ่ายทันที" ได้ |
| **รายการยืม-คืน** | สถานะ รออนุมัติ → กำลังยืม → คืนแล้ว (หรือ ไม่อนุมัติ/ยกเลิก), แจ้งเกินกำหนดคืน, คืนบางส่วนได้, บันทึกชำรุด/สูญหายตอนคืน, พิมพ์ใบยืม, ส่งออก CSV |
| **ประวัติสต็อก** | Log ทุกการเคลื่อนไหว (รับเข้า / ยืมออก / รับคืน / ปรับปรุงยอด / ชำรุด-สูญหาย) พร้อมยอดคงเหลือหลังทำรายการ กรองตามช่วงวันที่ ส่งออก CSV |
| **ข้อมูลพื้นฐาน** | จัดการหน่วยงาน/แผนก, หมวดหมู่อุปกรณ์, ผู้ใช้งานและสิทธิ์ |

### สิทธิ์ผู้ใช้
- **เจ้าหน้าที่คลัง (admin)** – อนุมัติ/จ่าย, รับคืน, จัดการสต็อกและข้อมูลพื้นฐานทั้งหมด
- **ผู้ใช้หน่วยงาน (staff)** – ดูสต็อกคงเหลือ, ส่งคำขอยืม, ดู/ยกเลิกคำขอของหน่วยงานตนเอง

### สต็อกเชื่อมกับการยืม-คืนอย่างไร
- `จำนวนทั้งหมด` = ที่โรงพยาบาลมีอยู่, `คงเหลือ` = อยู่ในคลังพร้อมให้ยืม, `ถูกยืม` = ทั้งหมด − คงเหลือ
- ส่งคำขอ → ยังไม่ตัดสต็อก (แต่ตรวจว่าของพอ)
- อนุมัติ/จ่าย → `คงเหลือ` ลดลง (ตรวจซ้ำใน transaction ป้องกันจ่ายเกิน)
- รับคืน → `คงเหลือ` เพิ่มกลับ / แจ้งชำรุด-สูญหาย → `จำนวนทั้งหมด` ลดลง
- ทุกครั้งบันทึกลง `stock_movements` ตรวจสอบย้อนหลังได้

## เริ่มใช้งาน

ต้องใช้ **Node.js 22.5 ขึ้นไป** (ใช้ SQLite ที่มากับ Node ไม่ต้องติดตั้งฐานข้อมูลแยก)

```bash
npm install
APP_SECRET="ตั้งค่าเป็นข้อความสุ่มยาว ๆ" npm start
# เปิด http://localhost:3000
```

บัญชีทดลอง (สร้างอัตโนมัติครั้งแรก พร้อมข้อมูลตัวอย่าง — **ควรเปลี่ยนรหัสผ่านทันที**)

| ชื่อผู้ใช้ | รหัสผ่าน | สิทธิ์ |
|---|---|---|
| `admin` | `admin1234` | เจ้าหน้าที่คลัง |
| `ward` | `ward1234` | ผู้ใช้หน่วยงาน (หอผู้ป่วยอายุรกรรมชาย) |

### ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเว็บ |
| `DB_FILE` | `data/borrow.db` | ไฟล์ฐานข้อมูล SQLite (สำรองไฟล์นี้เป็นประจำ) |
| `APP_SECRET` | สุ่มทุกครั้งที่เริ่ม | คีย์สำหรับ token เข้าสู่ระบบ ควรตั้งค่าเพื่อไม่ให้ผู้ใช้หลุดเมื่อรีสตาร์ท |
| `STOCK_API_KEY` | (ปิด) | เปิด API สต็อกสำหรับระบบอื่น |

## การเชื่อมข้อมูลกับระบบอื่น

1. **นำเข้า CSV** (เมนูคลังอุปกรณ์ → นำเข้า CSV) – ใช้ดึงยอดจากระบบคลังเดิม/Excel
   คอลัมน์: `รหัส, ชื่อ, หมวดหมู่, หน่วย, จำนวนทั้งหมด, จุดสั่งซื้อขั้นต่ำ, สถานที่เก็บ`
   รหัสเดิมจะถูกอัปเดตยอด (บันทึกเป็นการปรับปรุงยอด), รหัสใหม่จะถูกเพิ่ม
2. **ส่งออก CSV** – สต็อกคงเหลือ, รายการยืม-คืน, ประวัติสต็อก (เปิดใน Excel ภาษาไทยได้)
3. **REST API อ่านยอดคงเหลือ** – ตั้ง `STOCK_API_KEY` แล้วเรียก
   ```bash
   curl -H "X-API-Key: <key>" http://localhost:3000/api/public/stock
   ```
4. ทุกหน้าจอใช้ JSON API ภายใต้ `/api/*` (ส่ง header `Authorization: Bearer <token>` ที่ได้จาก `POST /api/login`) สามารถนำไปเชื่อมกับระบบอื่นได้
