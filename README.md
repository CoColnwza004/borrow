# ระบบยืม-คืนอุปกรณ์ โรงพยาบาล (Hospital Equipment Borrowing)

> **มี 2 แบบให้เลือก**
> 1. **แบบง่าย รันบน GitHub Pages (ฟรี)** อยู่ในโฟลเดอร์ `docs/` เก็บข้อมูลใน Google Sheets ไม่ต้องมีเซิร์ฟเวอร์ ← แนะนำให้เริ่มจากแบบนี้
> 2. **แบบเซิร์ฟเวอร์ (Node.js)** อยู่ในโฟลเดอร์ `src/`, `public/` มีระบบผู้ใช้/รหัสผ่านรายคน เหมาะกับการติดตั้งบนเซิร์ฟเวอร์ของโรงพยาบาล (รายละเอียดด้านล่าง)

## แบบง่าย: GitHub Pages + Google Sheets (ฟรี)

### ขั้นที่ 1: เปิดเว็บบน GitHub Pages (ประมาณ 2 นาที)
1. เข้า repo บน GitHub แล้วไปที่ **Settings → Pages**
2. ที่ **Source** เลือก **Deploy from a branch**
3. ที่ **Branch** เลือก `claude/magical-hamilton-g35q6e` (หรือ `main` ถ้ารวมโค้ดเข้า main แล้ว) แล้วเลือกโฟลเดอร์ **`/docs`** จากนั้นกด **Save**
4. รอ 1–2 นาที แล้วเว็บจะอยู่ที่ **https://cocolnwza004.github.io/borrow/**

ตอนนี้เว็บใช้งานได้แล้วใน **โหมดทดลอง** ข้อมูลเก็บในเบราว์เซอร์แต่ละเครื่อง และ PIN เจ้าหน้าที่คือ `1234`

### ขั้นที่ 2: เชื่อม Google Sheets เพื่อให้ทุกเครื่องใช้ข้อมูลเดียวกัน (ประมาณ 10 นาที)
1. สร้าง Google Sheet ใหม่ที่ https://sheets.new แล้วตั้งชื่อ เช่น "ระบบยืมอุปกรณ์"
2. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในหน้า Apps Script ให้ลบโค้ดเดิมในไฟล์ `Code.gs` ออก แล้ววางเนื้อหาจากไฟล์ [`docs/apps-script/Code.gs`](docs/apps-script/Code.gs)
   แก้บรรทัด `var ADMIN_PIN = '1234';` เป็น PIN ของคุณเอง
4. กด **+** ข้างคำว่า "ไฟล์" → **สคริปต์** แล้วตั้งชื่อว่า `Core` จากนั้นวางเนื้อหาจากไฟล์ [`docs/core.js`](docs/core.js)
5. กดบันทึก (รูปแผ่นดิสก์) เลือกฟังก์ชัน **`setup`** ในแถบด้านบน แล้วกด **เรียกใช้ (Run)**
   ครั้งแรก Google จะขอสิทธิ์ ให้กด อนุญาต → Advanced → ไปที่โปรเจกต์ → Allow
   จากนั้นในชีตจะมีแท็บ อุปกรณ์ / คำขอยืม / ประวัติสต็อก ฯลฯ พร้อมข้อมูลตัวอย่าง (แก้หรือลบได้)
6. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)** → ไอคอนเฟือง เลือก **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
   - กด Deploy แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
7. กลับมาที่ GitHub เปิดไฟล์ [`docs/config.js`](docs/config.js) กดรูปดินสอ (Edit) แล้ววาง URL ลงใน `API_URL: '...'`
   จากนั้นกด **Commit changes** แล้วรอ 1–2 นาทีให้ Pages อัปเดต

เสร็จแล้วครับ เปิด https://cocolnwza004.github.io/borrow/ จากเครื่องไหนก็จะเห็นข้อมูลชุดเดียวกัน

> ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้องไปที่ **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version** แล้วกด Deploy โค้ดใหม่จึงจะมีผล

### การใช้งาน
- **ทุกคน** ดูสต็อกคงเหลือ ส่งคำขอยืม และยกเลิกคำขอที่รออนุมัติได้
- **เจ้าหน้าที่คลัง** กด "เข้าสู่โหมดเจ้าหน้าที่" (มุมซ้ายล่าง) แล้วใส่ PIN เพื่ออนุมัติ/จ่าย, รับคืน, รับเข้าสต็อก, ตรวจนับ, ตัดชำรุด, เพิ่มอุปกรณ์, จัดการหน่วยงาน/หมวดหมู่
- เปิดดูข้อมูลทั้งหมดใน Google Sheet ได้ตลอด ถ้าแก้ **จำนวน** ควรแก้ผ่านเว็บ เพื่อให้มีประวัติสต็อกครบ

### ข้อควรทราบ
- repo นี้เป็น public ดังนั้นโค้ดและ URL ใน `config.js` เปิดให้ทุกคนเห็นได้ คนที่มีลิงก์จะดูสต็อกและส่งคำขอยืมได้ แต่ต้องมี PIN จึงจะอนุมัติหรือแก้สต็อกได้ (PIN อยู่ใน Apps Script ไม่ได้อยู่ใน GitHub)
- **ห้ามใส่ข้อมูลผู้ป่วย** (ชื่อ, HN) ในช่องวัตถุประสงค์หรือหมายเหตุ
- Google Apps Script ตอบสนองช้ากว่าเซิร์ฟเวอร์ทั่วไป (ประมาณ 1–3 วินาทีต่อการบันทึก) เหมาะกับปริมาณการใช้งานระดับโรงพยาบาลทั่วไป

## แบบเซิร์ฟเวอร์ (Node.js)

เว็บแอปสำหรับให้หน่วยงานภายในโรงพยาบาลยืม-คืนครุภัณฑ์/อุปกรณ์การแพทย์จากคลังกลาง
โดย **ยอดสต็อกคงเหลือเชื่อมกับการยืม-คืนแบบอัตโนมัติ** และบันทึกประวัติการเคลื่อนไหวทุกครั้ง

## ความสามารถหลัก

| เมนู | รายละเอียด |
|---|---|
| **ภาพรวม** | จำนวนอุปกรณ์ทั้งหมด / คงเหลือพร้อมให้ยืม / กำลังถูกยืม / รออนุมัติ / เกินกำหนดคืน, รายการสต็อกต่ำกว่าจุดขั้นต่ำ, ความเคลื่อนไหวล่าสุด |
| **คลังอุปกรณ์** | ค้นหา กรองตามหมวด ดูยอด *คงเหลือ / ทั้งหมด / ถูกยืม* แบบเรียลไทม์, ดูว่าใครยืมอยู่, ประวัติสต็อกรายชิ้น, รับเข้า, ตรวจนับปรับยอด, ตัดชำรุด/สูญหาย, นำเข้า/ส่งออก CSV |
| **ยืมอุปกรณ์** | เลือกหลายรายการในคำขอเดียว ระบบตรวจว่าไม่เกินยอดคงเหลือ, เจ้าหน้าที่คลังเลือก "จ่ายทันที" ได้ |
| **รายการยืม-คืน** | สถานะ รออนุมัติ → กำลังยืม → คืนแล้ว (หรือ ไม่อนุมัติ/ยกเลิก), แจ้งเกินกำหนดคืน, คืนบางส่วนได้, บันทึกชำรุด/สูญหายตอนคืน, พิมพ์ใบยืม, ส่งออก CSV |
| **ประวัติสต็อก** | Log ทุกการเคลื่อนไหว (รับเข้า / ยืมออก / รับคืน / ปรับปรุงยอด / ชำรุด-สูญหาย) พร้อมยอดคงเหลือหลังทำรายการ กรองตามช่วงวันที่ ส่งออก CSV |
| **ข้อมูลพื้นฐาน** | จัดการหน่วยงาน/แผนก, หมวดหมู่อุปกรณ์, ผู้ใช้งานและสิทธิ์ |

### สิทธิ์ผู้ใช้
- **เจ้าหน้าที่คลัง (admin)** – อนุมัติ/จ่าย, รับคืน, จัดการสต็อกและข้อมูลพื้นฐานทั้งหมด
- **ผู้ใช้หน่วยงาน (staff)** – ดูสต็อกคงเหลือ, ส่งคำขอยืม, ดู/ยกเลิกคำขอของหน่วยงานตนเอง

### สต็อกเชื่อมกับการยืม-คืนอย่างไร
- `จำนวนทั้งหมด` = ที่โรงพยาบาลมีอยู่, `คงเหลือ` = อยู่ในคลังพร้อมให้ยืม, `ถูกยืม` = ทั้งหมด − คงเหลือ
- ส่งคำขอ → ยังไม่ตัดสต็อก (แต่ตรวจว่าของพอ)
- อนุมัติ/จ่าย → `คงเหลือ` ลดลง (ตรวจซ้ำใน transaction ป้องกันจ่ายเกิน)
- รับคืน → `คงเหลือ` เพิ่มกลับ / แจ้งชำรุด-สูญหาย → `จำนวนทั้งหมด` ลดลง
- ทุกครั้งบันทึกลง `stock_movements` ตรวจสอบย้อนหลังได้

## เริ่มใช้งาน

ต้องใช้ **Node.js 22.5 ขึ้นไป** (ใช้ SQLite ที่มากับ Node ไม่ต้องติดตั้งฐานข้อมูลแยก)

```bash
npm install
APP_SECRET="ตั้งค่าเป็นข้อความสุ่มยาว ๆ" npm start
# เปิด http://localhost:3000
```

บัญชีทดลอง (สร้างอัตโนมัติครั้งแรก พร้อมข้อมูลตัวอย่าง — **ควรเปลี่ยนรหัสผ่านทันที**)

| ชื่อผู้ใช้ | รหัสผ่าน | สิทธิ์ |
|---|---|---|
| `admin` | `admin1234` | เจ้าหน้าที่คลัง |
| `ward` | `ward1234` | ผู้ใช้หน่วยงาน (หอผู้ป่วยอายุรกรรมชาย) |

### ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเว็บ |
| `DB_FILE` | `data/borrow.db` | ไฟล์ฐานข้อมูล SQLite (สำรองไฟล์นี้เป็นประจำ) |
| `APP_SECRET` | สุ่มทุกครั้งที่เริ่ม | คีย์สำหรับ token เข้าสู่ระบบ ควรตั้งค่าเพื่อไม่ให้ผู้ใช้หลุดเมื่อรีสตาร์ท |
| `STOCK_API_KEY` | (ปิด) | เปิด API สต็อกสำหรับระบบอื่น |

## การเชื่อมข้อมูลกับระบบอื่น

1. **นำเข้า CSV** (เมนูคลังอุปกรณ์ → นำเข้า CSV) – ใช้ดึงยอดจากระบบคลังเดิม/Excel
   คอลัมน์: `รหัส, ชื่อ, หมวดหมู่, หน่วย, จำนวนทั้งหมด, จุดสั่งซื้อขั้นต่ำ, สถานที่เก็บ`
   รหัสเดิมจะถูกอัปเดตยอด (บันทึกเป็นการปรับปรุงยอด), รหัสใหม่จะถูกเพิ่ม
2. **ส่งออก CSV** – สต็อกคงเหลือ, รายการยืม-คืน, ประวัติสต็อก (เปิดใน Excel ภาษาไทยได้)
3. **REST API อ่านยอดคงเหลือ** – ตั้ง `STOCK_API_KEY` แล้วเรียก
   ```bash
   curl -H "X-API-Key: <key>" http://localhost:3000/api/public/stock
   ```
4. ทุกหน้าจอใช้ JSON API ภายใต้ `/api/*` (ส่ง header `Authorization: Bearer <token>` ที่ได้จาก `POST /api/login`) สามารถนำไปเชื่อมกับระบบอื่นได้

## โครงสร้างโปรเจกต์

```
server.js          จุดเริ่มต้นเซิร์ฟเวอร์
src/db.js          โครงสร้างฐานข้อมูล + ข้อมูลตัวอย่าง
src/app.js         REST API ทั้งหมด (ยืม-คืน, สต็อก, ข้อมูลพื้นฐาน, รายงาน)
src/auth.js        รหัสผ่าน (scrypt) และ token
src/csv.js         อ่าน/เขียน CSV
public/            หน้าเว็บ (HTML/CSS/JS ไม่ต้อง build)
test/              ทดสอบ API (`npm test`)
```
